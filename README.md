# hackathon-pypro2352

## Inilah jenis proyek saya:
Ide saya adalah membuat website eco-calculator yang digabung dengan fitur klasifikasi gambar rumah yang ada lampunya. Nanti user bisa upload gambar rumahnya, dan nanti model akan menghitung jumlah lampu yang menyala, lalu memberikan saran untuk hemat energi

## Pustaka yang akan saya gunakan: 
1. flask
2. flask-sqlalchemy
3. tensorflow
4. keras
5. pillow
